```
□ Title tag 55-60 characters

□ H1 tag includes primary keyword
□ H2-H6 hierarchical structure
□ Alt text on all images
□ Schema markup implemented
□ Internal linking strategic
□ URL clean and descriptive
□ Mobile-responsive design
□ Page load speed <3 seconds

```
□ Primary CTA above the fold

□ Contact info easily accessible

□ HTTPS secure
□ Canonical tags set
