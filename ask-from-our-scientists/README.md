## Purpose

This repository contains structured technical questions and consultation requests for external scientific consultants working with Monoatom Labs on graphene-based product development, optimization, and validation.

**Target Audience:** PhD-level scientists, materials engineers, and technical consultants specializing in:
- Graphene and nanomaterials
- Construction materials
- Solar energy technology
- Polymer chemistry
- Ceramic coatings
- Composite materials
- Materials characterization

## How to Use This Repository

### For Monoatom Labs Team:

1. **Review Questions:** Go through relevant MD files before consultant meetings
2. **Add Context:** Update product context sections as new data becomes available
3. **Track Progress:** Mark questions as answered and document responses
4. **Prioritize:** Use priority tags (CRITICAL, HIGH, MEDIUM, LOW) for urgent questions
5. **Update Regularly:** Add new questions as they arise during product development

### For Consultant Scientists:

1. **Read Product Context:** Each file begins with comprehensive product background
2. **Review Questions:** Questions are organized by technical domain
3. **Provide Detailed Responses:** Include scientific rationale, references, and recommendations
4. **Request Additional Data:** Identify any missing information needed for complete answers
5. **Suggest New Directions:** Propose additional research or optimization opportunities

## Question Format Template

Each question file follows this structure:

```markdown
# Product Name - Consultation Type

## PRODUCT CONTEXT
[Comprehensive background about the product]

## CURRENT STATUS
[Development stage, claims, performance data]

## TECHNICAL QUESTIONS

### Category 1: [Domain]

**Q1.1: [Priority] Question Title**
**Context:** [Background information]
**Question:** [Detailed question]
**Why This Matters:** [Business/technical importance]
**Data Available:** [What we have]
**Expected Output:** [What we need]

**Status:** [OPEN / IN PROGRESS / ANSWERED / DEFERRED]
**Assigned To:** [Consultant name]
**Due Date:** [Date]
**Response:** [To be filled by consultant]
```

---

## Priority Definitions

- **CRITICAL:** Blocking product launch or customer commitment
- **HIGH:** Significant impact on product performance or cost
- **MEDIUM:** Important for optimization but not blocking
- **LOW:** Nice to have, future enhancement
