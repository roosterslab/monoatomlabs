# Answers — ask-for-business-details

These files answer each product’s business-details template using only `source-contents/`.

Notes:
- Sections like **revenue, margins, COGS, capacity, suppliers, pipeline, CAC/LTV, TAM/SAM/SOM** are **not** present in `source-contents/` and are explicitly flagged as **NEEDS INTERNAL DATA**.
- Pipeline products have only brief descriptions in `source-contents/` and therefore have shorter answer files.
