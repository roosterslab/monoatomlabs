# Ceraphene — Cost Comparison / ROI Calculator (customer-facing, source-contents grounded)

## Inputs (from source-contents)
- Ceraphene price: C_m = ₹5,000 per 50 ml
- Competitor average price: C_c = ₹15,000 per 50 ml
- Ceraphene durability: Y_m = 3–4+ years (range)

## Calculations
- Immediate savings per comparable application: S = C_c − C_m = ₹10,000
- Cost per protection-year (range):
  - CPY_m = C_m / Y_m
  - If Y_m = 3 years → CPY_m = 1,666.67 ₹/year
  - If Y_m = 4 years → CPY_m = 1,250 ₹/year

## What is missing for full ROI
