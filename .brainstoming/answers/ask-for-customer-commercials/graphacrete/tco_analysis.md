# Graphacrete — TCO Discussion Template (customer-facing, source-contents grounded)

`source-contents/` provides strength/durability-related claims but does not provide a quantified lifecycle-cost dataset. This file therefore provides a TCO structure and the minimum customer inputs needed.

## 3-year / 10-year TCO structure

### Baseline (customer inputs)
- Repairs due to cracking/leakage: ₹/year
- Waterproofing/sealing spend: ₹/year
- Downtime/quality failure cost: ₹/event and events/year

### With Graphacrete (customer inputs + assumptions)
- Expected reduction in crack repairs (needs field evidence)
- Expected reduction in permeability-related issues (needs field evidence)

## Claims you can cite (from source-contents)
- Water resistance improvement: 30–45%.
- Micro-crack control: “Excellent”.
- Compressive strength gain: 40–50%.

## Output
- Baseline TCO vs Graphacrete TCO
- Payback period given customer’s own baseline repair/maintenance costs

## Data needed to finalize a customer-ready TCO sheet
- 2–3 field projects with quantified reduction in repair events / waterproofing spend.
