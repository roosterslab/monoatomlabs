# Monoatom Labs Website

## Overview
This project is a React-based implementation of the Monoatom Labs website, transitioning from static HTML prototypes to a dynamic Vite application.

## Structure
- **Framework**: React + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: React Router DOM

## Components
- **Hero**: Implements the "Experiment 6" Monochrome Voltage Grid animation using HTML5 Canvas.
- **Products**: Interactive product showcase using data from the prototypes.
- **Technology**: Visual breakdown of the methodology.
- **Leadership**: Team section.
- **Layout**: Responsive Navbar and Footer.

## Styling
The design follows the "Monoatom Monochrome" aesthetic:
- **Colors**: primarily `neutral-950` (black) and `white`.
- **Fonts**: `Inter` (Body), `Outfit` (Display), `Space Grotesk` (Mono/Tech).
- **Animations**: Custom `fade-in`, `spin-slow` via Tailwind config.

## Development
Run `npm run dev` to start the development server.
